Binder Selection Agent — leadership demonstration

Decision-support for marine cargo / stock throughput placement. The system reads a submission, screens capacity, applies each binder's appetite rules, and recommends where to place. A named underwriter always decides — the system never binds.

At a glance

How it works (business view)

  1. Read — pull risk facts from broker documents, each with source and confidence.
  2. Completeness check — anything mandatory missing goes back to the broker as a named information request.
  3. Capacity screen — each binder's free capacity is derived (line minus written minus reserved); full binders are excluded with the shortfall stated.
  4. Appetite rules — every rule evaluated identically every time: Pass, Decline, or Cannot-assess.
  5. Rank & explain — eligible binders ranked by a published score, with a plain-English rationale.
  6. Underwriter decides — accept, override with a reason code, or refer back. Overrides and corrections are recorded.

Guardrails & honest limits


    

  • Rules live in versioned data with approval — never in prompts or code. Changing appetite needs no software release.
    • 

  • Missing information produces Refer or an information request, never a quiet Pass.
    • 

  • Every evaluation is immutable and replayable; corrections create linked successor records.
    • 

  • Not yet production: sign-in/roles, live capacity and geo-data feeds, binders C–E, and 10 business decisions awaiting owners (bands, tie-breaks, severity, retention).
