Quick reference

Workflows

  • Create a case → pick a sample or upload documents → click "Open case"
  • Run evaluation → pick extractor (stub/gemini/nvidia/openrouter) → click "Run evaluation ▶"
  • Record decision → accept (reserve capacity), override (different binder + reason), or refer back (opens a round)
  • Issue a round → tick gaps, add notes, click "Issue round to broker" → confirm dialog
  • Broker answers → broker logs in → portal → answer round → save draft → submit

Roles

  • Admin — full access, provision accounts, manage rules/capacity/reference
  • Underwriter — create/evaluate/decide cases, issue rounds, propose rulesets
  • Broker — portal only: own cases, ask-lists, documents, letters

Status vocabulary

StatusMeaning
newOpened, no evaluation yet. Assessment SLA ticking (3 business days).
assessedLatest evaluation ran; awaiting human decision.
awaiting-brokerA Request round is open; broker owes answers (10 business days).
decidedDecision recorded. Bound = terminal for this release.

Engine vocabulary

Pass (satisfied) · Decline (outside appetite, candidate-excluding) · Cannot assess (held, shown as "Needs information") · Refer (binder can't say yes/no) · Excluded (screened out before rules).

Shortcuts

Dark mode toggle in the topbar. Search box on the workboard filters by case ID, broker, or reference. Filter presets: All / Awaiting broker / Breached SLA.
